Агент, который живёт в терминале

Опишите задачу обычными словами. cdx прочитает репозиторий, поправит файлы и выполнит команды на машине, где запущен, - и спросит разрешение перед каждым изменением.

$ sudo apt install ./cdx_<version>_amd64.deb
$ cdx "почему ночной бэкап идёт 3 часа?"

Что ему поручают админы

Это не чат рядом с терминалом. Он работает в текущем каталоге на реальной машине: читает файлы, запускает команды и показывает, что изменил.

Разобраться в унаследованном коде

"Объясни, что делает этот сервис и какие порты слушает." cdx обходит репозиторий и отвечает со ссылками на файлы и строки, а не догадками.

Починить старые скрипты

"Скрипт сборки собирает по одной цели - пусть собирает пять." На выходе дифф, а не переписанный файл: те же флаги, те же имена, поменялись только циклы.

Работа с юнитами и логами

"Почему контейнер перезапустился в 3 ночи?" Читает journald, юниты и конфиги, затем называет причину и предлагает исправление.

Рутина без рутины

"Напиши systemd-юнит для этого бинарника, поставь лимиты, включи." Команды выполняются только после вашего подтверждения.

Настоящая сессия целиком

Реальная сессия, записана на обычной скорости и ускорена в 2.5 раза: скрипт сборки на 16 целей переделывается на пять параллельных сборок.

Время сессии: 2 мин 11 с, 15 шагов. Модель - выбранная по умолчанию; на записи подтверждения разрешений были выданы заранее.

Настоящий пример: build-all.sh

build-all.sh из Go-проекта собирает шестнадцать платформ одну за другой, потом варианты с GStreamer, потом цели под Android. На ноутбуке это перерыв на кофе, на сборочном сервере - простой ядер.

Как он устроен

Один бинарник для CLI и один демон в фоне. Каждая возможность - плагин, поэтому ядро остаётся маленьким: транспорт, хранилище, рантайм плагинов, цикл сессии.

CLIcdx "запрос", сессии на каталог, очередь, если два запроса пришли в одну папку
Демонхранит сессии, провайдеров и права; общается через unix-сокет, панель на 127.0.0.1:8787
Провайдерылюбой OpenAI-совместимый endpoint (OpenAI, DeepSeek, OpenRouter, Ollama, LM Studio) и Anthropic
Инструментычтение, поиск, правка, shell, субагенты, MCP-серверы как дополнительные инструменты

Спрашивает, прежде чем действовать

Каждая правка, каждая команда и каждый путь вне рабочего каталога проходят через проверку разрешений. Ответ по умолчанию для неразрешённого действия - "нет".

В запросе видно команду, рабочий каталог и все внешние пути до того, как вы ответите. Enter выбирает вариант по умолчанию - "разрешить один раз".

По классам действий

Чтение, правка и опасные инструменты имеют allow, ask или deny; отдельная настройка решает, что делать вне рабочего каталога.

Правила опасных команд

Шаблоны вроде rm -rf, git push --force и mkfs помечены как критичные и не проходят как обычные.

Действие целиком, а не пересказ

Никаких "агент что-то хочет сделать": видно точную команду, файл или каталог, которые будут изменены.

Локально по умолчанию

Панель слушает 127.0.0.1 и требует токен; удалённый доступ - явное включение с предупреждением. Запросы уходят только настроенному провайдеру.

Установка

Пакеты для i386, x86_64, armv7 и aarch64 собираются к каждому релизу. Берите тот, который понимает ваш дистрибутив.

Debian / Ubuntu (.deb)

Файл cdx_<version>_amd64.deb возьмите на странице релизов.

sudo apt install ./cdx_<version>_amd64.deb
Fedora / RHEL / openSUSE (.rpm) 
sudo dnf install ./cdx-<version>-1.x86_64.rpm
Alpine (.apk)

Пакет не подписан, поэтому нужен флаг.

sudo apk add --allow-untrusted ./cdx_<version>_x86_64.apk
Любой Linux (zip + install.sh) 
unzip cdx_<version>_linux_x86_64.zip -d cdx
sudo ./cdx/install.sh          # /usr/bin/cdx и /usr/share/cdx/plugins
Из исходников

Нужны Go 1.27+ и Node.js 22+, чтобы собрать бинарник и панели.

make                 # веб-интерфейс, панели плагинов, бинарник
sudo make install    # /usr/bin/cdx и /usr/share/cdx/plugins

Первый запуск

Поднимите демон, откройте панель, добавьте провайдера и модель.

cdx daemon run --http 127.0.0.1:8787

Страница настроек

Поднимает демон, если нужно, и открывает панель в браузере.

cdx --config

Один запрос

Работает в текущем каталоге и сохраняет сессию для следующего запроса.

cdx "объясни этот пакет"
